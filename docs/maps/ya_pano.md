# Яндекс.Панорамы (3D-фотосферы)

Модуль позволяет просматривать **3D-панорамы и фотосферы Яндекса** для визуальной оценки качества дорожного покрытия, поиска объездов и детального планирования велосипедных маршрутов прямо в редакторе Велокэта.

Модуль полностью переработан в версии **v3.3.4**: он функционирует автономно в обход платных лимитов API Яндекса, не вызывает Cross-Origin блокировок браузера и поддерживает сквозной интерактивный режим перемещения.

---

### 🗺️ Интерфейс и активация режима

![Панель инструментов Велокэта](images/pano_activation.png)
*Рисунок 1. Кнопка активации режима панорам на панели Leaflet.*

1. **Кнопка включения:** На левой панели инструментов Leaflet расположен значок бинокля (`L.easyButton`).
2. **Панель статуса:** При активации кнопка окрашивается в синий цвет, а в информационной строке Велокэта загорается статус: `<i class="fa fa-binoculars"></i> Режим просмотра панорам`.
3. **Блокировка кнопок:** Во избежание порчи active-трека мусорными точками, редактор автоматически усыпляет кнопки режимов («Ручной трек», «Автопрокладка», «Маркеры» и «Удаление») с помощью метода `.disable()`.
4. **Визуальный курсор:** На холсте карты стрелочка мыши меняется на аккуратный информационный знак вопроса (`cursor: help`), подсказывая, что клик откроет панораму. Над сайдбаром и кнопками Leaflet нативно сохраняется стандартный указатель-рука (`pointer`).

### 🕹️ Интерактивное управление («Клик + Drag-and-Drop»)

Модуль работает в режиме бесконечного сквозного просмотра через два сценария управления:

* **Активация кликом:** При первом нажатии на бинокль всплывает отдельное окно встроенного браузера `window.open` с приветственной надписью. Окно центрируется на экране. При клике в любое место карты в этой точке рождается синий маркер-бинокль, а окно мгновенно загружает 3D-фотосферу Яндекса.

![Окно ожидания и первый клик](images/pano_popup_welcome.png)
*Рисунок 2. Стартовое окно-подсказка для пользователя перед выбором точки на карте.*

* **Перетаскивание (Dragend):** Синий маркер на холсте имеет параметр `draggable: true`. Вы можете плавно тащить его мышкой вдоль дорог — при наведении на маркер курсор меняется на ладонь захвата (`grab/grabbing`), а в момент отпускания кнопки мыши (`dragend`) панорама в открытом окне Яндекса автоматически обновляет обзор под новые координаты.

### 🔄 Автоматическое выключение и синхронизация

* **Ручное отключение:** Повторное нажатие на синюю кнопку бинокля удаляет маркер с карты, стирает кастомные CSS-курсоры, закрывает всплывающее окно Яндекса и возвращает кнопки рисования трека в рабочее состояние.
* **Закрытие крестиком:** Если пользователь закрывает вкладку панорам нативным крестиком браузера, в монолите Велокэта срабатывает ежесекундный фоновый таймер `setInterval`. Он безопасно считывает флаг `.closed`, мгновенно ловит закрытие окна, стирает синий бинокль с холста карты и нативно разблокирует все серые кнопки редактора (`deleteButt.enable()`, `selectButton.enable()`), возвращая карту к штатному рисованию.

### ⚙️ Технические особенности интеграции (для разработчиков)

* **Cross-Origin безопасность:** Модуль полностью очищен от устаревших методов `document.write()` внутри асинхронных потоков. Всплывающее окно рождается в безопасном контексте `about:blank`, а обновление фотосфер происходит через прямую нативную перезапись `yandexPanoWindow.location.href`, что исключает появление в консоли критической ошибки безопасности `Uncaught SecurityError`.
* **Экономия бюджета:** Интеграция использует прямой веб-интерфейс геосервиса Яндекса по сквозным координатам `ll={lng},{lat}&panorama[point]={lng},{lat}` вместо виджета JavaScript API. Это позволяет Велокэту бесплатно обрабатывать неограниченное количество кликов пользователей, экономя коммерческий лимит API (150 000 рублей в год).
