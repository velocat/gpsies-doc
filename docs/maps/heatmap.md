# Велотреки пользователей (Векторный слой PBF)

Оверлей **«Велотреки пользователей» (UserTracks)** — это высокотехнологичный слой, который стримит векторную геометрию всех поездок Велокэта в режиме реального времени с локального `tileserver` в формате Protobuf (`.pbf`). Слой служит интерактивной подложкой-подсказкой для точечной обводки маршрутов по существующим трекам.

---

### ⚙️ Технологический стек и оптимизация скорости

![Векторная сетка треков](../_media/usertracks_mesh.png)
*Рисунок 2. Отображение изящных векторных нитей прошлых поездок.*

* **Canvas-рендерер (`L.canvas.tile`):** Отрисовка тысяч нитей переведена со стандартного SVG на аппаратный Canvas-тайл. Это разгрузило DOM-дерево браузера, ликвидировало фризы интерфейса при сдвиге карты и обеспечило скорость рендеринга 60 FPS.
* **Слайдер «Яркость слоя треков»:** Слева от переключателя слоев для оверлея выводится персональный жирный пульт управления. Изменение прозрачности завязано на нативный метод Leaflet `.setOpacity()`. Бегунок кэширует значение в LocalStorage (`wt.vectorGridOpacity`), благодаря чему уровень яркости жестко фиксируется и не сбрасывается при перемещении и зуме карты.
* **Асинхронный синхронизатор (Хук на 'load'):** Для победы над гонкой таймингов при перезагрузке страницы перебор элементов привязан к нативному событию `.on('load')` плагина VectorGrid. Стили накладываются строго в тот момент, когда векторный буфер полностью скачался из сети.

### 🕵️‍♂️ Динамические стили и фильтрация приватности

Отрисовка векторных путей происходит динамически через функцию `track(properties, zoom)` на основе внутренних метаданных PBF-фичи:

1. **Жесткий фильтр конфиденциальности:** Система считывает права доступа. Если трек помечен в базе как приватный (`properties.priv == 1`), а текущий `currentUid` не совпадает с ID автора трека (`properties.uid`), слой полностью скрывает эту нить, возвращая пустой стиль `{stroke: false, fill: false}`.
2. **Умная толщина и цвет:** Свои приватные треки подсвечиваются оранжевым/красным, чужие публичные — мягким синим цветом. Толщина линий изящно уменьшается при отдалении карты (`weight: 0.5 - 1.2`), чтобы подложка оставалась тонкой паутиной и не забивала экран.

### 🦓 Адаптивный пунктир пассивных сегментов (Юзабилити Рисования)

Чтобы пассивные сегменты текущего редактируемого маршрута (которые по умолчанию имеют бледный лиловый оттенок) не терялись на фоне огромной массы синих векторных дорог, в модуль внедрен **динамический пунктирный хак**:

* При установке галочки «Велотреки пользователей» ядро Велокэта запускает пакетный метод `forEachSegment()`. Все пассивные сегменты вашего текущего трека на лету утолщаются (`weight + 1.5`), поднимают плотность (`opacity: 0.95`) и превращаются в контрастную пунктирную «зебру» (`dashArray: '8, 6'`).
* Метод `segment.redraw()` принудительно очищает графический кэш холста, выводя штрихованный трек на самый передний план.
* При выключении оверлея или снятии галочки система автоматически возвращает все сегменты к исходным сплошным бледным линиям и восстанавливает их оригинальные динамические цвета из базы данных квадратиков. Активный трек рисования при этом защищен от изменений на 100%.
